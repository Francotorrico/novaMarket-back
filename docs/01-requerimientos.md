# Requerimientos

## Objetivo

Desarrollar una API REST para NovaMarket que permita gestionar usuarios, productos, carrito y pedidos.

---

## Actores y Funcionalidades

### Cliente

- Registrarse
- Iniciar sesión
- Ver catálogo
- Filtrar productos
- Agregar productos al carrito
- Realizar checkout

### Administrador

- Iniciar sesión
- Crear productos
- Editar productos
- Eliminar productos
- Ver pedidos

---

## Fuera del MVP

- Pago real
- Envíos
- Aplicación móvil
- Integraciones externas
